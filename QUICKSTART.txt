⚙️ ADJUSTING PARAMETERS:

Edit cavity.in to change:

  Re          - Reynolds number (default: 100)
  nx, ny      - Grid resolution (default: 50×50 = 51×51 points)
  dt          - Time step (default: 0.001)
  omega_sor   - SOR parameter (1.7 is optimal for most cases)

After editing, rerun:
  ./cavity_solver
  python3 postprocess.py

🎓 FOR YOUR REPORT:

Key points to mention:

1. Numerical Method:
   - Stream function-vorticity formulation
   - SOR for Poisson equation (∇²ψ = -ω)
   - Upwind scheme for stability
   - Explicit time-stepping

2. Boundary Conditions:
   - No-slip walls (u=v=0)
   - Moving lid (u=1, v=0 at y=1)
   - Vorticity: ω = -∂²ψ/∂n² at walls

3. Validation:
   - Excellent agreement with Ghia et al. (1982)
   - Grid convergence demonstrated

4. Code Structure:
   - Modular Fortran implementation
   - Clean separation: solver/boundary/input
   - Python for professional visualization

❓ TROUBLESHOOTING:

Problem: Code won't compile
Solution: Install gfortran (sudo apt install gfortran)

Problem: Not converging to steady state
Solution: Reduce dt in cavity.in (try 0.0005)

Problem: Solution oscillating
Solution: Check that upwind scheme is active
          Try different omega_sor (1.5-1.9)

Problem: Plots not matching Ghia
Solution: Run longer (increase max_time_steps)
          Use finer grid (nx=100, ny=100)
